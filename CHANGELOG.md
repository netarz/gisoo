# Changelog

## 1.0.0 (2026-10-03)

- First release: what Gisoo is, the app's features, the API at `https://gisoo.pro/api/v1`.
- `claude-code/`: Claude Code on Gisoo (bash, PowerShell, `settings.json`, VS Code).
- `anthropic/`: the official Anthropic SDK (Python, Node.js) and curl on `/messages`.
- `openai/`: the official OpenAI SDK (Python, Node.js) and curl.
- `media/`: images, video jobs, music, text-to-speech and speech-to-text.
- CI: syntax checks only; it never calls the API.
